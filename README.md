# デリスト（Delist / Delusion Story）

OpenRouter API を使って、好きな LLM で **AI ロールプレイ** と **自動ストーリー進行** を楽しめる Web UI です。

## 特徴

- 🎭 **ロールプレイ** — キャラクターの人格・口調・舞台を設定して自然な会話
- 📖 **自動ストーリー進行** — 「続ける」ボタンで AI が物語を自律的に展開。入力で介入も可能
- 🔀 **モデル選択** — OpenRouter で使える全モデルを検索・お気に入り登録して切替
- 💾 **履歴の保存/読込** — セッションはブラウザのローカルストレージに自動保存
- ⚡ **ストリーミング表示** — 生成テキストを逐次表示／途中停止・やり直し対応

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 が自動で開きます。

### API キーの設定

1. [openrouter.ai/keys](https://openrouter.ai/keys) で API キーを取得
2. アプリ左下の「⚙ API キー / 設定」からキーを登録

> キーはブラウザのローカルストレージにのみ保存され、OpenRouter への API リクエスト以外には送信されません。

## 使い方

| 操作 | 説明 |
| --- | --- |
| ＋ ロールプレイ / ＋ 物語 | 新しいセッションを作成 |
| 右上の ⚙ | キャラクター/物語の設定・創造性・最大トークンを編集 |
| 右上のモデル名 | 使用モデルを変更（無料モデルは「free」で検索） |
| ▶ 物語をはじめる / ⏩ 続ける | （物語モード）自動進行 |
| ↻ やり直す | 直前の AI 応答を破棄して再生成 |

## 技術構成

- React 18 + TypeScript + Vite
- Zustand（状態管理 + localStorage 永続化）
- OpenRouter Chat Completions API（SSE ストリーミング）

## ビルド

```bash
npm run build      # dist/ に静的ファイルを出力
npm run preview    # ビルド結果をローカルで確認
```

`dist/` は静的ファイルなので、任意の静的ホスティングに置けます。
