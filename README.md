# デリスト（Delist / Delusion Story）

好きな LLM で **AI ロールプレイ**と**自動ストーリー進行**を遊ぶアプリです。
**ブラウザ版**（インストール不要）と**デスクトップ版**（Windows）があり、中身は同じものです。

**API キーは利用者が用意します**（BYOK）。当方のサーバーは介在せず、生成は利用者が選んだ提供元へ直接送られます。
**ローカルモデル（Ollama など）を接続先にすれば、外部通信なしでも動きます**（→ [ローカル LLM で動かす](docs/ガイド_ローカルLLMで動かす.md)）。

## 始め方

### 1. ブラウザで試す（インストール不要）

公開 URL を開いて、**接続先を1つ設定するだけ**です。ダウンロードも署名の警告もありません。

> **公開 URL はまだ用意していません。** 公開の可否と置き場所は未決です（手元で試すには下の「開発」の `npm run dev`）。

1. 初回にウィザードが開きます。「かんたん接続」なら OpenRouter の承認画面へ移動し、戻ってくると接続が済んでいます（API キーの貼り付けでも構いません）
2. 初回だけ**サンプルの世界観・登場人物とサンプルの物語が入ります**。ウィザード最後の「サンプルの物語を開く」からそのまま読み始められます（消したあとは「作る」画面の「サンプルを追加し直す」で戻せます）
3. 自分の物語を始めるときは**「一行から始める」**。一行の前提（例:「廃校寸前の高校の写真部」）から世界観・登場人物・最初の一場面を AI が起案し、セッション設定が開きます。中身を直して「保存」すればそのまま始められます

**データはそのブラウザの中にだけ保存されます**（下記「データの保存場所」）。
ブラウザのメニューから**ホーム画面／アプリとして追加**すると、単独のウィンドウで開けます（PWA）。

> ブラウザ版から**自分の PC のローカル LLM**につなぐときだけ、サーバ側で接続元を許可する設定が要ります
> （→ [ローカル LLM で動かす §11](docs/ガイド_ローカルLLMで動かす.md)）。デスクトップ版では不要です。

### 2. 気に入ったらデスクトップ版（Windows）

保存先がファイルになり、ブラウザの制約（CORS・サイトデータの削除）が無くなります。

1. インストーラ（`.exe`）を実行します
2. **未署名のため Windows の SmartScreen が警告を出します。**「詳細情報」→「実行」で進めてください
   （コード署名証明書は年間費用がかかるため、需要が見えてから取得を判断します）
3. あとはブラウザ版と同じです。ブラウザ版のデータは System の「全データをエクスポート」で持ち込めます

## 動作環境

- **ブラウザ版**: Chrome / Edge / Firefox / Safari の新しめのもの（スマートフォンでも本文は読めますが、画面は PC 向けです）
- **デスクトップ版**: Windows 10 / 11（64bit）
- 接続先の LLM: OpenRouter・OpenAI 互換 API・Gemini（OpenAI 互換エンドポイント）・**ローカル（Ollama / LM Studio）**
- 画像生成（任意）: OpenRouter / OpenAI 互換の画像 API / **ComfyUI（ローカル）**

## API キーと接続先

初回ウィザードで、次のいずれかを選べます。

| 選択肢 | 内容 |
|---|---|
| かんたん接続 | OpenRouter を OAuth で接続（キーのコピペが不要） |
| 無料枠で始める | Gemini の無料枠。**入力が提供元の品質改善に使われうる**点に注意 |
| 品質重視 | OpenRouter に手持ちのキーを登録 |
| PC で動かす | ローカルモデル（Ollama など）。**外部にデータを送りません** |

**デスクトップ版の API キーは Windows の資格情報マネージャー**（サービス名 `com.tokatokage.delist`）に保存され、
設定ファイル（`state.json`）には平文で書き込まれません。**ブラウザ版はブラウザの保存領域**に入ります
（外部には送られませんが、その端末のブラウザを使える人には見えます）。

## データの保存場所

### ブラウザ版

物語・キャラクター・世界観・画像は**そのブラウザの中にだけ**保存されます（`localStorage` と IndexedDB）。

- **消える条件**: ブラウザの「閲覧データの削除」で Cookie とサイトデータを消したとき／プライベートウィンドウを閉じたとき／端末の空き容量が逼迫してブラウザが古いサイトのデータを削ったとき
- **別のブラウザ・別の端末・別のアドレスとは共有されません**（アドレスが変わると別のデータとして扱われます）
- **バックアップと持ち出し**は System の「全データをエクスポート」（JSON バンドル）。同じ画面から取り込めます

### デスクトップ版

```text
%APPDATA%\com.tokatokage.delist\data\
  state.json      … キャラクター・世界観・カセット・表示設定・接続先
  sessions\       … 物語（セッション）1本ごとに1ファイル
  images\         … 生成・添付した画像
  checkpoints\    … 分岐用のチェックポイント
```

- **バックアップ**は、アプリを終了した状態で `data` フォルダをまるごとコピーするだけです
- **別 PC への移行**も同じ手順でできます。ただし **API キーは資格情報マネージャー側にある**ので移動しません（移行先で入れ直してください）
- **クラウド同期フォルダに置く場合**: キーは含まれませんが、**物語の本文と画像はそのまま入っています**。同期先の共有範囲に注意してください
- 同期フォルダに置くときは、**複数の PC で同時に起動しない**でください（`state.json` は起動中のアプリが持つ状態で上書きされます）

### アンインストールしたときに消えるもの・残るもの

| | アンインストール時 |
|---|---|
| アプリ本体 | 消えます |
| **API キー**（資格情報マネージャー） | **消えます**（更新のときは消えません） |
| **物語・キャラクター・画像**（`data` フォルダ） | **残ります。** アンインストーラの「アプリケーションデータを削除」に**チェックを入れたときだけ**消えます |

書いたものを誤って失わないよう、既定では物語データを残します。**完全に消したいときはチェックを入れてください。**
逆に、消したくないものがある場合は、アンインストールの前に `data` フォルダをコピーしておくのが確実です。

## 開発

```bash
npm install
npm run dev           # ブラウザ版（Vite・5173）
npm run tauri:dev     # デスクトップ版（Rust ツールチェーンが必要）
```

デスクトップ版のビルドには Rust ツールチェーンが必要です。

> Web 版とデスクトップ版では、通信（CORS の有無）・ファイル保存・状態の保存先が異なります。
> これらに触る変更は `npm run tauri:dev` で確認してください。

## ビルド

```bash
npm run build                  # ブラウザ版の静的ファイルを dist/ へ
npm run tauri:build            # デスクトップ版（インストーラを含む）
npm run tauri build -- --no-bundle   # 実行ファイルのみ（インストーラを作らない）
```

`dist/` は**そのまま静的ホスティングに置けます**（パスは相対なのでサブパス配信でも動きます。
Service Worker と PWA のインストールには HTTPS が必要）。手順は [`docs/開発環境と配布.md`](docs/開発環境と配布.md) §2b。
インストーラは `src-tauri/target/release/bundle/` に出力されます。
`--no-bundle` を付けない初回ビルドでは、**バンドラ（NSIS など）をインターネットから取得します**。

## 技術構成

- React 18 + TypeScript + Vite（ブラウザ版は PWA。アプリシェルのみをキャッシュする Service Worker 付き）
- Zustand（状態管理）＋ ファイル永続化（デスクトップ版）／localStorage・IndexedDB（ブラウザ版）
- Tauri 2（デスクトップ・`plugin-http` / `plugin-fs` / `plugin-dialog`）
- OpenAI 互換 Chat Completions API（SSE ストリーミング）

設計・実装の詳細は [`AGENTS.md`](./AGENTS.md) を参照してください。
