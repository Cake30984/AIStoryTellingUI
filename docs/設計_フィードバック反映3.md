# 設計: フィードバック反映 第3弾（FB3）

- 日付: 2026-07-11
- 経緯: FB2 実装後の実使用フィードバック第3ラウンド。本文表示の煩雑さ・分岐ツリーの根本不具合・演出ディレクターの存在意義・カード体系（セッションカード／カセット）の再編。

## 2. ユーザー決定事項（2026-07-11 合意）

- **セッションカードは読み書きとも完全撤去**。関連コードごと削除し、過去に書き出した `aist_session` PNG は今後読み込めなくなる。共有はカセット（最初から遊ぶ）に一本化、バックアップ用途は System のデータ書き出しが担う。
- **カセットは専用エディタで作成**（「作る」のカセット棚に「＋カセットを作る」）。加えて、遊んで調整済みのセッションを「カセットの下書きとして開く」導線も残す。
- **表紙は任意の画像ファイルから選択可能に**（自動生成・挿絵に加えて）。
- **演出（シーンタイプ）は素材ごと全廃**。Library の演出タブ・SceneType 素材・セッション設定の演出欄を削除し、世界観イベントに一本化。イベントの自動発火は存続し**既定 ON**（セッション設定で OFF 可）。
- **分岐ツリーはフルグラフ**（SourceTree 風。全ノードを縦1列＋レーン線・色分け・折りたたみなし）。
- 自動スクロールは全廃（自分の操作直後の1回のみ）。
- 「選択肢を生成」は最後の assistant メッセージのアクション行にのみ表示。
- クリエイト画面は新設せず「作る」エリアの拡張で対応。

## 3. FB3-A: 本文表示と操作の即効改善（実装済み・2026-07-11）

- **A1 開始シーン見出し**: `showDivider` の条件 `session.scenes.length > 1` を「シーンにメッセージ（マーカー以外）または要約があれば1シーン目でも表示」に変更。未開始（メッセージ0件）ではヒントのみ表示で見出しは出さない。
- **A2 マーカーの罫線化＋生成単位の区切り線**:
  - マーカー（`CONTINUE_PROMPT`/`SCENE_START_PROMPT`）は novel/chat 両モードとも細い水平線 `.gen-divider` として描画。テキスト・`msgActions` なし → 「ここから」重複（FB3-3）も同時解消（本文側のみ残る）。
  - 通常のユーザー発言（プロンプト入力・選択肢クリック）の前にも `.gen-divider` を1本（入力文自体は従来どおり表示に残す）。
  - シーン境界は「線＋📖見出し」のセットのみ: scene-divider 自体に上線を持たせ、直後の SCENE_START マーカーは線を描かない（二重線回避）。
- **A3 自動スクロール停止**: ストリーミング追従の `useEffect`（毎チャンク発火）を撤去。「末尾メッセージの id が変わり、かつ role==='user'」のときだけ1回スクロール（＝自分の送信・続ける・選択肢クリックの直後のみ。生成中は一切追従しない）。
- **A4 分岐ノードのラベル**: `actionCheckpointLabel` を「末尾 assistant 本文の冒頭」優先に変更。`plainTextOf`（構造化マークアップ除去）→ 空白正規化 → 14字程度＋… 。編集 `✏`／削除 `🗑` の接頭辞は現行維持、導入も本文冒頭を使う。
- **A5 一覧の選択 UX**:
  - `useMultiSelect` に Escape で `clear()`（選択が空でないときのみ処理・capture で先取りし、`shortcuts.ts` の没入解除 Escape は `defaultPrevented` を尊重して衝突回避）。
  - `SelectionBar`（Sidebar／Library 共通）は `selected.size >= 2` のときのみ表示。右クリック1件選択はハイライトと右クリックメニューのみ。
  - CSS: 表示中セッション `.active` を控えめに（薄い背景＋左アクセントボーダー程度）、`.selected` をアクセント背景で明確に強調。
- **A6 選択肢を生成**: `msgActions` に「そのメッセージが最後の assistant メッセージ」のときのみ「選択肢を生成」ボタンを追加 → `regenChoices()`。生成中（`isGeneratingChoices` 等）は無効。

## 4. FB3-B: 分岐チェックポイントの分岐化＋フルグラフ UI（実装済み・2026-07-12）

### B1 データ側（やり直しを枝にする）

- `BranchNode` に `anchorMessageId?: string`（記録時セッションの末尾メッセージ id）を optional 追加 → persist キー据え置き。
- 巻き戻し系操作（`regenerate`/`regenerateFrom`/`editMessage`/`deleteMessage`）の冒頭で `reanchorBranch(sessionId, keptMessageIds)` を呼ぶ: `currentId` から祖先へ遡り、`anchorMessageId ∈ kept` である最初のノードへ `currentId` を移す（該当なしなら動かさない）。以降の `recordCheckpoint` はそのノードの子として積まれる＝**git の checkout→commit と同じく兄弟分岐になる**。
  - kept の定義: regenerateFrom／regenerate＝切り詰め後に残る message id 集合。deleteMessage＝削除後の集合。editMessage＝編集対象**より前**の集合（内容が変わったため対象自身は不一致扱い）。
  - reanchor は単独でも整合する（currentId は「いま論理的に立っている地点」であり、切り詰め直後はその祖先に立っている）。生成が中断されて checkpoint が積まれなくても矛盾しない。
  - anchor を持たない旧ノードは常に不一致＝既存の木では従来動作にフォールバック。既存セッションの直列の木はそのまま残る（壊れない。気になる場合は剪定で整理）。
  - 既知の割り切り: `editMessage` は id を変えないため、編集を挟んだ履歴では親選びが編集前のノードに寄ることがある（id ベースの近似）。厳密化（content hash 併用）は必要になったら。
- `restoreCheckpoint`・dedupe・書込直列化・ルート遅延生成は現行維持。

### B2 UI（BranchTreeBody 全面書き換え）

- 現行の主線／章折りたたみ／⑂別の分岐／▷この先は**全廃**し、コミットグラフ1本に:
  - 全ノードを1行ずつ縦に並べ（深さ優先: 現在パスを優先レーン、他の枝は createdAt 順）、SVG でレーン縦線＋分岐・合流の曲線を描画。レーンごとに色（`tokens.css` にグラフ用パレット変数を追加）。
  - 行 = 色ドット＋ラベル＋timeLabel＋★バッジ。現在ノードは「いまここ」強調。scene ノードは 📖＋太字のマイルストーン表示。
  - 行 hover で「↩ ここに戻る」、⋯メニュー（しおり設定/解除・シーン開始前へ戻る・この分岐を削除）は維持。
  - ★しおりタブ・「✂ 現在の分岐だけ残す」・容量表示・currentId への自動スクロールは維持。
  - 旧 `.bt-*` CSS は新クラス体系（`.bg-*` 等）へ整理。

## 5. FB3-C: 演出ディレクター廃止（世界観イベント一本化）

- `types.ts`: `SceneType`・`Session.director`・`Scene.sceneTypeId` を削除。`Session.eventAutoFire?: boolean`（既定 true）を追加。
- `store.ts`: `sceneTypes` state・既定6種シード・`directNextScene` のタイプ抽選を削除し、イベント判定のみの `nextScheduledEvent(session, world, day)` に縮小（未消化・day 到来・condition 成立の優先判定は現行踏襲）。`eventAutoFire === false` なら発火しない。`startStory`/`confirmSceneReview` のシーン命名はイベント名 or timeLabel ベースに。
- `resolveRefs` の `sceneTypeGuidance`・prompts の【今回のシーンの方向性】はイベント note のみを流す形に整理。
- UI: Library ナビの「演出」・SceneTypeLibrary・SessionEditor 進行タブの演出欄を削除。進行タブに「イベントの自動発生」トグル（既定 ON）を追加。
- `exportBundle`/`importBundle` から sceneTypes を除去。旧 persist データに残る余剰キー（director 等）は無害のため persist キーは据え置き。
- CLAUDE.md のディレクター・SceneType 記述を同コミットで更新。

## 6. FB3-D: カード再編（セッションカード全廃＋カセット専用エディタ）

- **D1 セッションカード全廃**: `cards.ts` の `exportSessionCard`/`importSessionCard`・`parseCardPng` の `aist_session` 分岐を削除（カセットは維持）。Sidebar 右クリック「カード化」・SessionEditor フッターの「セッションをカード化」・System ページ／D&D のセッションカード読み込み経路を除去。`SessionCardModal` のセッションカードモードを廃止。
- **D2 カセットエディタ（CassetteEditor）**: カセット棚に「＋カセットを作る」→ 専用編集画面（WorldEditor 方式のセクションナビを想定。セクション: 基本〔タイトル・紹介文・表紙〕／世界観／キャラクター／ペルソナ／導入・開始設定）。
  - 内部は `Cassette.session`（開始状態のセッション）を直接編成: `newSession` 相当の素体に世界観選択→`startPresetPatch` 適用など、SessionEditor の部品・ロジックを再利用。Play のセッション一覧には現れない。
  - 表紙: タイトルから自動／**任意の画像ファイル**（`normalizeImage`→`putImage`）／セッション種の場合は挿絵からも選択。
  - 保存で `cassettes` に upsert。PNG 書き出しは棚の既存ボタンを継続利用。
- **D3 セッション→下書き導線**: セッション右クリック／⋯メニューに「カセットにする…」→ `freshSessionOf(session)` を種に CassetteEditor を開く（旧「カード化」モーダルの置き換え。プレイ記録・モデル参照の初期化は現行 `freshSessionOf` を踏襲）。

## 7. 実装順序と検証

推奨順: **A（即効・小修正群）→ B（最大の不満点）→ C → D**。C・D は互いに独立、B は A4 と近接するが独立。

各フェーズで `npx tsc --noEmit` → `npm run build`。ユーザー実機確認項目:
1. 新規セッション開始直後（導入文あり／なし両方）に 📖 シーン見出しが出る（A1）
2. 「続ける」「選択肢」「プロンプト」の各操作後、境目が細い線1本になり、マーカー文言と「ここから」重複が消えている（A2）
3. 生成中に上へスクロールしても引き戻されない。送信直後だけ1回下へ移動（A3）
4. 分岐タブのノード名が生成本文の冒頭になっている（A4）
5. Ctrl/Shift 選択→Esc で解除。バーは2件以上でのみ表示。表示中セッションと選択の色が見分けられる（A5）
6. 最後の本文の下に「選択肢を生成」が出て動く（A6）
7. 「ここから」やり直し→分岐タブで**別の枝**として描かれる（B1）。グラフの線・色で枝が追える（B2）
8. シーン終了→次シーンがイベント or 自由な流れで始まる。演出タブ・演出欄が消えている（C）
9. カセット棚から新規作成→表紙に任意画像→PNG 書き出し→取込→▶遊ぶ が一巡する。セッションカードの導線が消えている（D）
