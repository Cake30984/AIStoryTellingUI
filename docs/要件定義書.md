# AI ストーリーテリング ツール 要件定義書

## 1. 文書の目的
本書は、AI を用いたロールプレイおよび物語創作を支援するツールについて、現時点で実現済みの機能を要件として整理したものである。実装方式・利用技術には言及せず、利用者から見た「何ができるか」を定義する。

## 2. システム概要
本ツールは、利用者が AI と対話しながらキャラクターとのロールプレイや、自動的に進行する物語づくりを楽しむための環境である。キャラクター・世界観・ペルソナといった素材を再利用可能な形で管理し、それらを組み合わせて物語のセッションを進められる。物語は「シーン」という区切りで管理され、長い物語でも一貫性を保ちながら進行・引き継ぎができる。

## 3. 用語定義
| 用語 | 定義 |
| --- | --- |
| セッション | 1つの物語／ロールプレイの単位。会話履歴と各種設定を持つ |
| キャラクター | 物語に登場する人物の設定。再利用可能な素材 |
| 世界観 | 物語の舞台設定。共通設定と、状況に応じて参照される個別設定からなる |
| ペルソナ | 利用者自身が演じる人物の設定。再利用可能な素材 |
| シーン | 物語の一区切り。登場人物・状況・要約を持つ |
| 要約（あらすじ） | シーン終了時に作成される引き継ぎ用のまとめ |
| シーンタイプ | シーンの種類（日常・バトル等）。次シーンの方向づけに用いる |
| レビュー | シーン終了時に要約・次シーン案・設定の追補をまとめて確認する工程 |

## 4. 対象利用者・利用シーン
- AI とのキャラクターロールプレイを楽しみたい利用者
- AI と協働して長編の物語を創作したい利用者
- 自分専用の素材（キャラ・世界観）を蓄積し、繰り返し物語づくりに活用したい利用者

## 5. 機能要件

### 5.1 セッション管理
- FR-1: 利用者は「ロールプレイ」または「物語」のモードでセッションを新規作成できる。
- FR-2: 利用者は複数のセッションを保持し、一覧から選んで再開できる。
- FR-3: 利用者はセッションのタイトルを編集できる。
- FR-4: 利用者はセッションを削除できる。

### 5.2 モデルの選択
- FR-5: 利用者は物語生成に用いる AI モデルを選択・切替できる。
- FR-6: 利用者は本編生成用のモデルとは別に、補助処理（要約・提案・選択肢生成など）用のモデルを指定できる。未指定時は本編用モデルが用いられる。
- FR-7: 利用者は生成の創造性の度合いおよび応答の最大長を調整できる。

### 5.3 キャラクター管理
- FR-8: 利用者はキャラクターを作成・編集・複製的に蓄積・削除できる素材として管理できる。
- FR-9: キャラクターには名前・人格・口調・外見・セリフ例・最初のセリフ・タグなどを設定できる。
- FR-10: 同一のキャラクターを複数のセッションで再利用できる。
- FR-11: 物語の進行に伴って判明・深化した設定を、元の設定とは区別して「追加設定」として蓄積できる。
- FR-12: 追加設定は項目ごとに有効／無効を切り替えられ、無効化したものは物語に反映されない。

### 5.4 世界観管理
- FR-13: 利用者は世界観を作成・編集・削除できる素材として管理できる。
- FR-14: 世界観は、常に参照される「概要」と、特定のキーワードが会話に登場したときにのみ参照される「個別設定」に分けて登録できる。
- FR-15: 個別設定は項目ごとに有効／無効、および常時参照の有無を切り替えられる。
- FR-16: 物語の進行で判明した世界設定を、元の設定と区別して追加できる。
- FR-17: 世界観に、特定の時点（期間内の特定日）に発生する「特別イベント」を日付指定で登録できる。

### 5.5 ペルソナ管理
- FR-18: 利用者は自分が演じる人物（ペルソナ）を作成・編集・削除できる素材として管理できる。
- FR-19: ペルソナをセッションごとに選択して適用できる。

### 5.6 セッションの構成
- FR-20: 各セッションに、参加キャラクター（複数可）・世界観・ペルソナを組み合わせて設定できる。
- FR-21: 各セッションに、常に踏まえてほしい固定メモを設定できる。

### 5.7 物語の進行（対話）
- FR-22: 利用者はメッセージや行動を入力し、AI の応答を得られる。
- FR-23: 物語モードでは、入力なしでも物語を自動的に先へ進められる。
- FR-24: 直前の AI 応答を破棄して作り直せる。
- FR-25: AI の応答は生成途中から逐次表示され、利用者は生成を途中で停止できる。

### 5.8 グループ会話（複数キャラクター）
- FR-26: 1つのセッションに複数のキャラクターを登場させられる。
- FR-27: 次に発言するキャラクターを利用者が指定できるほか、AI に任せて自然な話者を選ばせることもできる。

### 5.9 文体スタイル
- FR-28: セッションごとに、文章の表現方式を「小説形式（地の文と会話文を織り交ぜた文章）」または「会話劇（キャラクターごとの発言）」から選べる。

### 5.10 選択肢による進行
- FR-29: AI の応答後に、次の行動の選択肢を提示させられる。
- FR-30: 選択肢の提示方式を「提示しない」「毎回提示」「AI が適切と判断した場面のみ提示」から選べる。
- FR-31: 提示された選択肢を選ぶと、その内容に沿って物語が続く。利用者は選択肢に頼らず自由入力することもできる。

### 5.11 シーン管理
- FR-32: 物語は「シーン」という区切りで管理される。
- FR-33: 各シーンに、時・場所・その場に居る人物を含む状況メモを設定できる。状況メモは物語の進行に反映される。
- FR-34: シーンを終えるたびに、次のシーンの状況メモ（時・場所・居合わせる人物）が自動で用意され、確定前に確認・編集できる。
- FR-35: シーンを終了すると、その間の会話の要約（引き継ぎメモ）が作成される。
- FR-36: 終了したシーンの会話は折りたたんで保持され、必要に応じて見返せる。要約は後から編集できる。
- FR-37: 過去のシーンの要約は、それ以降の物語進行に引き継がれる。

### 5.12 タイムライン（期間と区切り）
- FR-38: 物語全体の期間（総日数や呼称）と、1日内の区切り単位（朝・昼・夜、1日ごと等）を設定できる。
- FR-39: シーンを終えると時間が1区切り進み、次のシーンの時刻が自動的に設定・命名される。
- FR-40: 現在の時刻と残り期間が物語進行に反映され、終盤では収束へ向かうよう促される。

### 5.13 シーン終了レビュー
- FR-41: シーン終了時に、以下を1つの確認画面でまとめて確認・承認できる。
  - 当該シーンの要約（編集可）
  - 次のシーンの方向性の提案（複数案から選択、または自分で決める）
  - 物語の展開を踏まえたキャラクターの成長案（採否を個別に選択）
  - 物語の展開を踏まえた世界設定の追加案（採否を個別に選択）
- FR-42: 承認した成長・追加設定は、元のキャラクター・世界観の素材に反映される。

### 5.14 シーン演出（次シーンの方向づけ）
- FR-43: シーンの種類（例：日常の幸福、穏やかな時間、バトル、バトルへの伏線、過去回想、特別イベント）を素材として管理できる。
- FR-44: 各シーンタイプに、出やすさ（重み）と、連続発生を避けるための最低間隔を設定できる。
- FR-45: セッションごとに、抽選対象とするシーンタイプを選べる。
- FR-46: シーン終了時、次のシーンの種類を重みと最低間隔に基づいて自動的に抽選し、偏りや単調さを抑える。
- FR-47: 世界観で日付指定された特別イベントが該当日に到来した場合は、抽選より優先して発生する。発生済みのイベントは再発生しない。
- FR-48: 抽選結果はレビュー画面で確認でき、利用者は種類を変更したり抽選し直したりできる。

### 5.15 あらすじの閲覧
- FR-49: これまでの全シーンの要約を時系列で一覧・通読できる。
- FR-50: 一覧の内容をまとめて取り出せる。

### 5.16 会話の編集
- FR-51: 個々のメッセージの内容を編集できる。
- FR-52: 個々のメッセージを削除できる。
- FR-53: 任意の地点から会話を作り直せる（その地点以降を破棄して再生成する）。

### 5.17 データの保全
- FR-54: 作成した素材（キャラ・世界観・ペルソナ・シーンタイプ）とセッションは継続的に保持され、再訪時に引き継がれる。
- FR-55: 全データをまとめて書き出し（バックアップ）でき、書き出したデータを読み込んで復元できる。読み込み時は既存データを保持したまま統合される。

## 6. 非機能要件
- NFR-1（操作性）: わかりやすい画面で、専門知識がなくても主要操作を行える。
- NFR-2（応答性）: 生成中の文章は逐次表示され、待ち時間中も進捗が分かる。中断も可能とする。
- NFR-3（コスト配慮）: 補助処理を別モデルに分けられること、過去シーンを要約に圧縮して引き継ぐことにより、長い物語でも処理量を抑えられる。
- NFR-4（コストの可視化）: 現在のシーンのおおよその分量を表示し、区切りの目安を利用者に示す。
- NFR-5（データ可搬性・保全）: データの書き出し／読み込みにより、バックアップおよび移行ができる。
- NFR-6（一貫性）: 世界観・キャラクター設定・固定メモ・過去のあらすじを踏まえ、物語の一貫性を保つ。

## 7. 制約・前提
- 本ツールの物語生成は外部の AI モデルの利用を前提とし、利用にあたり利用者が必要な認証情報を登録する。
- モデルの利用にはモデル提供側の料金が発生しうる。

## 8. 本書のスコープ外（今後の検討事項）
- キャラクターへの画像設定、および物語中の挿絵の自動／手動生成。
- 上記に伴う画像データの保存・管理。

> 本書は実現済み機能の範囲を対象とする。記載の各要件は利用者から見た振る舞いを定義するものであり、実装方式・採用技術は規定しない。
