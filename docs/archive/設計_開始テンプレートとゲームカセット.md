# 設計: 世界観の開始テンプレートとゲームカセット

2026-07-11 の要望検討に基づく2フェーズの実装手順書。

- **W1: 世界観の開始テンプレート**（実装済み・2026-07-11）
- **W2: ゲームカセット専用カード**（実装済み・2026-07-11）

## 背景・要望

1. セッション設定にある「ジャンル・トーン」「あらすじ・前提」「固定メモ」は世界観素材に含まれておらず、世界観カードにも乗らない。これらを世界観（とそのカード）に持たせたい。ただしセッション側から自由に書き換えられ、**元の世界観素材は書き換わらない**こと。
2. 「ゲームカセット」的なカードが欲しい: 世界観・登場キャラ・ペルソナ・ジャンル・あらすじ・固定メモなど**物語を始めるために必要な情報が1枚にまとまり、読み込めばすぐ遊べる**カード。

## 現状分析（2026-07-11 時点）

- `World` に genre/premise/authorNote 相当のフィールドは**無い**。すべて Session 側:
  - ジャンル・トーン／あらすじ・前提／主人公像 → `session.story: StorySetup`
  - 固定メモ → `session.authorNote`
  - これらは `session.mode === 'story'` のときのみプロンプト注入・UI 表示（authorNote は両モード共通）
- `story.protagonist` は型・プロンプト注入（prompts.ts）にあるが **SessionEditor に入力 UI が無かった**（既存の欠落。W1 で追加）
- 世界観カード（`aist_world`）は `World` を丸ごと格納 → World にフィールドを足せばカードへ自動同梱
- **セッションカード（`aist_session`）は既に「1枚全部入り」の自己完結バンドル**: session＋キャラ全員＋世界＋ペルソナ＋画像実体（base64）を PNG 1枚に同梱し、読み込むと素材はライブラリへ id マージで分離して入る。ゲームカセットに足りないのは「プレイ記録を含まない開始状態」だけ

## 決定事項（選択式質問での合意）

| 論点 | 決定 |
|---|---|
| 開始テンプレートの範囲 | **フルセット**: ジャンル・トーン／あらすじ・前提／主人公像／固定メモ／タイムライン定義 |
| セッションへの反映方式 | **空欄のみ自動＋手動ボタン**: 世界を選んだ瞬間に空欄項目だけコピー。「開始テンプレートを読み込む」ボタンで全項目上書き（確認つき） |
| 反映の仕組み | **コピー方式**（参照・オーバーレイではない）。以後の編集はセッション側の値のみ変わり、素材は不変 |
| ゲームカセットの実現方式 | **専用カード種別 `aist_cassette` を新設**（第5のカード種）。中身はセッションカードと同じ全部入り PNG だが、プレイ記録を含まない開始状態＋カセット固有メタを持つ |

### 却下した代替案

- **オーバーレイ方式**（World を参照し実効ビューで合成）: genre/premise は単一自由テキストで丸ごと書き換えが普通。差分管理の意味が薄く、既存 SessionEditor の UI がそのまま使えるコピー方式が単純
- **フォルダ一括インポート**: Web 版のフォルダ D&D の UX が悪い・配布に zip が必要＝1ファイル形式の再発明・PNG カードの見た目の魅力を失う
- **完全に閉じたカセット（読み込み後も素材へ分離されない）**: Session は素材を id 参照する構造（resolveRefs／実効ビュー）のため「埋め込み素材」概念の新設が全経路に波及する大工事。カセット PNG 自体が原本として残るので自己完結性はそれで足りる
- **セッションカード拡張（cassette フラグ）案**: 実装は最小だが、ユーザーは「ゲームカセット」を独立したカード種として扱いたい意向 → 専用種別を採用

## W1: 世界観の開始テンプレート（実装済み）

### データモデル

`types.ts` に `WorldStartPreset` を追加、`World.startPreset?: WorldStartPreset`（optional 追加＝persist キー据え置き）。

```ts
interface WorldStartPreset {
  genre?: string        // → session.story.genre
  premise?: string      // → session.story.premise
  protagonist?: string  // → session.story.protagonist
  authorNote?: string   // → session.authorNote
  /** 定義のみ（currentDay/currentSlot は持たない＝常に1日目から） */
  timeline?: { slots: string[]; totalDays: number | null; spanLabel: string }
}
```

### 反映ロジック（store.ts の純関数）

- `startPresetPatch(d: Session, world: World, overwrite: boolean): Partial<Session>`
  - overwrite=false（世界選択時の自動反映）: **空欄の項目のみ**埋める
  - overwrite=true（手動ボタン）: テンプレートに値がある項目を**全上書き**
  - story 系（genre/premise/protagonist）は `d.mode === 'story'` のときのみ反映（roleplay では未使用のため不可視データを作らない）
  - timeline の「空欄」判定 = `enabled === false`（一度も有効化していない）。反映時は `enabled: true, currentDay: 1, currentSlot: 0` で流し込む
- `hasStartPreset(world): boolean` — 中身が1項目でもあるか（ボタン表示判定）

### UI

- **WorldEditor**: セクション「開始テンプレート」を basic の直後に追加。genre/premise/protagonist/authorNote の入力＋「タイムライン定義を含める」チェック（ON で spanLabel／totalDays／slots=CsvInput を編集）
- **SessionEditor（基本タブ）**:
  - 世界観 select の変更時に `startPresetPatch(d, world, false)` を draft へ適用（空欄のみ）
  - 選択中の世界に開始テンプレートがあれば「開始テンプレートを読み込む（全項目上書き）」リンクを表示 → `appConfirm` 確認後に overwrite=true で適用
  - **主人公像の入力欄を追加**（story モード時。プロンプト注入されるのに編集欄が無かった既存欠落の修正）

### カード・入出力

- `WorldCard` は `World` 丸ごと格納のため書き出しは自動追従。`normalizeWorldFromData`（cards.ts）に `startPreset` の正規化を追加（世界観カード・セッションカード同梱 world の両方が通る）
- `ExportBundle` も worlds 丸ごとのため自動追従

## W2: ゲームカセット専用カード（実装済み）

> 実装は下記設計とほぼ一致。差分メモ:
> - 画像収集は `collectCardImages`（セッションカードと共通）＋サイズ確認 `confirmImageSize`＋model 除去 `stripCharacterModels` に切り出し、`exportSessionCard`/`exportCassetteCard` で共用
> - `importCassette` は初期化を持たず `importSessionCard` へ委譲（カセットの session は書き出し時点で `freshSessionOf` 済み＝取り込みはセッションカードと完全同一。画像 remap・素材 id マージ・新規セッション追加・アクティブ化）
> - 書き出し UI は SessionCardModal にモード切替（続きから＝セッションカード / 最初から＝ゲームカセット）として統合。カセット時は紹介文入力欄を出す
> - 読み込みは Sidebar D&D・System ファイル入力の両方でカセット分岐（🎮 表示）。各 Library の D&D は従来通り自種別以外を弾く

### カード形式

- PNG tEXt チャンク `aist_cassette`・spec `'aist_cassette'`・spec_version `'1.0'`
- 中身 `CassetteBundle` = `SessionCardBundle` と同構造（session＋characters＋world＋persona＋images）＋カセット固有メタ:
  - `description?: string` — カセットの紹介文（読み込み確認・一覧表示用）

### 書き出し

- `exportCassetteCard(session, refs, cardImageBlob, description)`（cards.ts）
- セッションを**開始状態に初期化**する `freshSessionOf(session)` を通してから同梱:
  - 初期化: `messages=[]`・`scenes=[新シーン1つ]`・`currentSceneId`・`state`（空）・`overlay`（空）・`usedEventIds=[]`・`spriteEmotions=[]`・timeline を `currentDay=1, currentSlot=0` へリセット・`archived` 除去
  - モデル参照は環境固有のため空へ: `model=''`・`reviewModel=''`・`choicesModel=''`（`mainModelOf` 等が DEFAULT_MODEL にフォールバックするため受け手側で安全）
  - 残す: title・story・authorNote・characterIds・worldId・personaId・choiceMode・narrativeStyle・director・structuredOutput・timeline 定義・temperature・maxTokens・spritesEnabled
  - 同梱画像はアバター・立ち絵のみ（挿絵・背景は scenes 初期化により自然に対象外）
- 発見ロア・キャラ成長を「最初から入り」で配りたい場合は `promoteOverlayLore`/`promoteOverlayDev` で素材へ昇格してから書き出す運用（overlay は初期化されるため）

### 読み込み

- `parseCardPng` に `{ kind: 'cassette', bundle }` を追加（`aist_session` より先に判定）
- store に `importCassette(bundle)` — 実装は `importSessionCard` と同一処理を共通化して呼ぶ（画像 remap・素材 id マージ・セッション追加・アクティブ化）
- 同じカセットの再読み込み = 素材は既存優先でスキップ・まっさらな周回セッションだけが増える（周回プレイ動線）

### UI・導線

- 書き出し: SessionEditor フッター（または SessionCardModal 内の切替）に「ゲームカセットとして書き出す」。description 入力欄つき
- 受付: 既存の Sidebar D&D／System ページのファイル入力が `parseCardPng` 経由のため分岐追加のみ。読み込み時トーストや確認に「🎮 ゲームカセット」表示
- 各 Library の D&D はキャラ/世界/ペルソナカード用のため、カセットは Sidebar（play 領域）で受ける

### 規約チェックリスト（実装時）

- 画像 id を持つ新フィールドは増やさない（既存の収集・remap 経路をそのまま使う）
- `<a download>` 禁止 → `downloadBlob` 経由（既存 export 関数と同じ）
- PNG 組み立てはセグメント連結方式（push spread 禁止）
- モーダルは ModalShell・確認は appConfirm
