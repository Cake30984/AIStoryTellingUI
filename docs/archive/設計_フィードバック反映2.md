## 1. 問題・要望インベントリ（診断つき）

| # | 報告 | 診断・根本原因 | 対応 |

## 2. ユーザー決定事項（2026-07-11 合意）

- **導入文は「そのまま掲載」**: AI に生成させず、導入文を最初の本文としてそのまま表示する（AI が膨らませる方式は不採用。将来トグル追加は可能性として残す）。
- **セッション設定 UI は3案すべてをブランチで実装**して実機で試し、採用案を選ぶ（タブ強調／縦1ページ／左セクションナビ）。→ **左セクションナビを採用**（2026-07-11、実機比較の上で決定）。
- **カセット PNG の取り込みは「棚に登録のみ」**: 即セッション化はやめ、遊ぶときに「▶ 遊ぶ」で新しいセッションを作る。棚＝素材、と役割を明確化。
- 主人公像（`story.protagonist`・`WorldStartPreset.protagonist`）は削除。
- 分岐ツリーの症状は「枝が1本につながって見える」で確定（診断と一致）。

## 3. プロンプト注入タイミング（FB2-5 への回答の記録）

大原則: **system プロンプトは生成のたびに毎回ゼロから組み立て直す**（`prompts.ts buildSystemPrompt`）。「一度だけ注入」される項目は存在しない。

| セッション設定の項目 | 入り方 |
|---|---|
| タイトル | 入らない（表示専用） |
| 参加キャラ | 毎回【登場人物】（現在シーンの登場キャラのみ。人格・口調・外見・成長・セリフ例） |
| 世界観 | 毎回【世界観】。概要は常に全文、ロアは直近の会話にキーワード一致した項目のみ都度選別 |
| ペルソナ | 毎回【ユーザーが演じる人物】 |
| ジャンル・トーン／あらすじ・前提／主人公像 | 毎回【物語設定】（story モードのみ） |
| 固定メモ | 毎回【常に踏まえる重要事項】 |
| タイムライン | 毎回【時間】（現在の日・時間帯・残り日数。残り15%でクライマックス促し） |
| 選択肢で進行 | 本編には入らない（応答後に選択肢用モデルへ別リクエスト） |
| 演出ディレクター | シーン切替時に抽選→採用タイプの guidance がそのシーン中毎回【今回のシーンの方向性】 |
| モデル・創造性・最大トークン | 入らない（API パラメータ） |
| 文体スタイル／構造化出力 | 毎回（執筆ルール／【セリフの出力形式】ブロック切替） |

設定項目以外に毎回入るもの: これまでのあらすじ（終了シーンの要約）・現在の場面（シーン状況メモ）・状態（関係性/気分/注入対象スタット）。会話履歴は現在シーンの発言のみ全文。

## 4. フェーズ実装記録（全フェーズ完了・2026-07-11）

### FB2-A: 即効修正

- **A1**: `newSession` の `maxTokens` 既定を 4096→32768（スライダー最大に一致）。既存セッションは不変。
- **A2**: `drag-over` の付与先を `.card-grid`/`.library-empty` から `.library` ルートへ移動（Character/World/Persona の3ライブラリ）。CSS は `.library.drag-over`（outline 内側 + accent-soft 背景）に置換。
- **A3**: `SessionCardModal` を開いた時点で `generateDefaultAvatar` を実行し、「自動生成」を**プレビュー付きサムネイル**（「タイトルから自動」キャプション）に変更。挿絵ゼロでもサムネを表示。ObjectURL はアンマウントで revoke。
- **A4**: `renderMainNode` の枝描画を `offChildren.map(c => <div className="bt-alt">{renderSubtree(c.id)}</div>)` に変更（枝ごとに独立した囲み）。`.bt-alt + .bt-alt { margin-top: 8px }` で枝間に間隔。

### FB2-B: 開始体験（導入文・主人公像削除・開始時間帯）

- `types.ts`: `session.story` を `{ genre, premise, opening, openingTitle }` に変更（`protagonist` 削除）。`WorldStartPreset`・`Timeline`（`startDay?`/`startSlot?`）も同様。
- `store.ts`: `newSession`/`startPresetPatch`/`hasStartPreset` を更新。`startStory` は `story.opening` が非空なら **AI 生成せず** assistant メッセージとして掲載（`openingTitle` を見出しに優先）→ チェックポイント記録（label「🎬 導入」）→ choiceMode≠off なら選択肢生成。空なら従来の `beginScene()`。
- `prompts.ts`: `buildSystemPrompt` の `主人公:` 注入行を削除。
- `SessionEditor.tsx`: 主人公像欄を削除し「導入（見出し／本文・任意）」欄を追加。進行タブに開始時間帯セレクト（保存時、未開始なら現在位置を `startDay`/`startSlot` として記録）。
- `WorldEditor.tsx` 開始テンプレート: 主人公像欄→導入欄に差し替え、タイムラインに開始日・開始時間帯入力を追加。
- `cards.ts`: `normalizeStartPreset` を更新（protagonist 読み捨て・opening/openingTitle 受理）。`freshSessionOf` は `currentDay: tl.startDay ?? 1, currentSlot: tl.startSlot ?? 0` へ巻き戻す。
- persist `merge` で旧セッションの `story` を後方補完（`.trim()` の例外防止）。
- 互換: optional 追加＋不要フィールド削除のみ → persist キー据え置き。

### FB2-C: セッション設定 UI（左セクションナビ案を採用）

3ブランチ（`fb2c-tabs-emphasis`＝タブ強調／`fb2c-single-page`＝縦1ページ／`fb2c-section-nav`＝左セクションナビ）を実機比較し、**`fb2c-section-nav`（左セクションナビ・WorldEditor と同じ操作感）を採用**。`.se-navlayout`/`.se-nav`/`.se-panel` で左に基本／進行／モデル／出力のナビ、右にパネル。モーダルは `wide` 化。他2案のブランチ（ローカル・リモート）は削除済み。

### FB2-D: ライブラリ操作性（右クリック＋複数選択削除）

- 対象: セッション一覧（Sidebar）＋キャラ／世界観／ペルソナ／演出の各ライブラリ。
- `useMultiSelect`（Ctrl/Cmd=個別トグル、Shift=直近アンカーから範囲、右クリック選択）＋ `LibraryMultiSelect.tsx`（`SelectionBar`/`CardContextMenu`）。
- カード右クリック→ `MenuPopover`（編集／削除。複数選択中は「選択した n 件を削除」。セッションは＋一括アーカイブ）。
- 素の左クリックは従来の「開く」を優先（修飾キー時のみ選択）。削除確認は `appConfirm({danger:true})`。

### FB2-E: カセット棚

- `types.ts`: `Cassette { id, title, description, coverImageId?, session: Session, createdAt }`（session は開始状態。参照素材はライブラリへマージ済みの id 参照）。AppState 直下に `cassettes: Cassette[]`（persist・partialize 対象）。
- **GC 規約**: `collectUsedImageIds` に cassettes 分（`sessionImageIds(c.session)` ∪ `coverImageId`）を追加。
- `exportBundle`/`importBundle` に cassettes を追加（画像同梱オプションの対象）。
- `importCassette(bundle, cover?)` を「棚に登録のみ」へ変更（素材マージ・画像 remap は従来通り、セッションは作らない。表紙＝取込カード PNG を `putImage`）。Sidebar D&D／System ページの文言更新。
- `playCassette(id)`: `cassette.session` を新 id で複製して sessions へ追加・アクティブ化（何度でも最初から）。`deleteCassette(id)` で棚から除去。
- UI: `CassetteLibrary.tsx`＋Library ナビに「🎮 カセット」追加（一覧カード=カバー・タイトル・紹介文・▶遊ぶ・PNG書き出し・削除）。Sidebar に「カセットから遊ぶ」導線。

## 5. 検証

各フェーズで `npx tsc --noEmit` → `npm run build` を実施し通過済み。見た目・UX の実機確認はユーザー担当。確認項目:
1. 同じ地点から3つ以上分岐を作り、「⑂ 別の分岐」を開くと枝が**別々の囲み**で表示される（A4）
2. セッションカード化モーダルの「タイトルから自動」にプレビュー画像が出る・クリックで選択枠が付く（A3）
3. 新規セッションの最大トークンが 32768 になっている（A1）
4. カード PNG をライブラリへドラッグすると点線枠がページ全面に出る（A2）
5. 物語セッションの設定で導入（見出し・本文）を入力→「物語をはじめる」で AI を待たずその文章で開始（B）
6. タイムライン有効・未開始のセッションで開始時間帯を選択→開始するとその時間帯から始まる（B）
7. セッション設定モーダルが左ナビ＋右パネルの構成になっている（C）
8. 作る＞各ライブラリで Ctrl/Shift クリック→選択バーや右クリックで一括削除できる（D）
9. カセット PNG をドロップ→「作る＞カセット」棚に並ぶ→「遊ぶ」で新規セッション開始（E）
