# 利用規約とプライバシー

デルシア（Delusia。以下「本アプリ」）の利用条件と、データの扱いです。
提供者はサークル「とかとかげ」（以下「当方」）。本アプリは**無料**で、ソースコードは [MIT ライセンス](../LICENSE)で公開しています。

2026-09-16 制定。変更するときはこのファイルを更新します（履歴は git にあります）。

## 1. 本アプリの仕組み（前提）

- 本アプリは**利用者の端末（ブラウザまたは PC）の中だけで動きます**。当方のサーバーは介在しません
- 文章や画像を生成するとき、本アプリは**利用者が選んで設定した提供元（OpenRouter・OpenAI 互換 API・Gemini・ローカルモデル等）へ直接**リクエストを送ります。当方はその内容を受け取らず、見ることもできません
- **ローカルモデル**（Ollama・LM Studio・ComfyUI など、利用者の PC で動くもの）だけを接続先にした場合、**外部にはいっさい送信しません**
- 利用状況の自動送信（テレメトリ）は**ありません**

## 2. 利用条件

1. **提供元の規約は利用者の責任で守ってください。** 各提供元（OpenRouter、Google、OpenAI 等）の利用規約・利用ポリシーは、利用者と提供元の間の契約です。成人向けの内容を扱う場合も、**扱えるかどうかは提供元の規約が決めます**。本アプリは内容による制限を設けていませんが、提供元が拒否したものを通す手段も提供しません
2. **API の利用料は利用者の負担です。** 費用の目安は [README](../README.md) に書いていますが、実際の請求は提供元の料金体系と利用者の使い方で決まります。当方は費用の補償をしません
3. **生成された内容に当方は関与しません。** 生成物は提供元のモデルが利用者の入力に応じて出したものです。内容の正確さ・適法性・妥当性について当方は責任を負いません。生成物の権利関係は、利用者が選んだ提供元の規約に従います
4. **法令を守ってください。** 文章であっても法令の対象になります（「文章だから安全」ではありません）。適法性の判断は利用者が行ってください
5. **保証はありません。** 本アプリは現状有姿で提供されます。動作・データの保持・将来の継続について、いかなる保証もしません。データの消失（特にブラウザ版）に備えて、System 画面の「エクスポート」で定期的にバックアップしてください
6. **動作を確認している接続先**: OpenRouter（OAuth・手動キー）／OpenAI 互換 Chat Completions（Gemini の互換エンドポイントを含む）／Ollama／LM Studio／画像は OpenRouter・OpenAI 互換の画像 API・ComfyUI。これ以外での動作は未確認です。確認済みのものも、提供元側の変更で動かなくなることがあります
7. **返品・返金**: 無料のため該当しません

## 4. プライバシー

### 4.1 当方が受け取る情報

**ありません。** 本アプリは当方のサーバーと通信しません。当方は利用者が誰か、何を書いたか、どの提供元を使ったかを知ることができません。

ブラウザ版は静的ファイルの配信に GitHub Pages を使っています。ページを開いたときの接続情報（IP アドレス等）は、配信元である GitHub の[プライバシーに関する声明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)に従って GitHub が扱います。当方はそれを閲覧しません。

### 4.2 外部に送られる情報と送り先

| 何が | どこへ | いつ |
|---|---|---|
| 物語の本文・登場人物・世界観・利用者の指示（プロンプト） | 利用者が設定した LLM の提供元 | 文章を生成するたび |
| 挿絵の指示文 | 利用者が設定した画像生成の提供元 | 画像を生成するたび |
| API キー | その提供元（認証のため） | 上記のリクエストごと |

送り先は**利用者が設定したものだけ**です。送られた内容の扱い（保存期間・学習利用の有無）は各提供元のポリシーに従います。
**無料枠（Gemini 等）を選ぶと、入力が提供元の品質改善（学習）に使われることがあります。** 初回ウィザードにも同じ注意を表示しています。

### 4.3 API キーの保存場所

- **デスクトップ版（Windows）**: Windows の資格情報マネージャー（サービス名 `com.tokatokage.delusia`）に保存します。設定ファイル `state.json` には平文で書き込みません。アンインストール時に削除されます
- **ブラウザ版**: ブラウザの保存領域（localStorage）に保存します。外部には送られませんが、**その端末のブラウザを使える人には見えます**。共用の端末では使わないか、使い終わったら System 画面で接続先を削除してください

### 4.4 その他のデータの保存場所

物語・キャラクター・世界観・画像・分岐のチェックポイントは、すべて利用者の端末にだけ保存されます（デスクトップ版は `%APPDATA%\com.tokatokage.delusia\data\`、ブラウザ版はブラウザの localStorage と IndexedDB）。詳細と消える条件は [README](../README.md) の「データの保存場所」を見てください。
