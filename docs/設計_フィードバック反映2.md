## 2. ユーザー決定事項（2026-07-11 合意）

- **導入文は「そのまま掲載」**: AI に生成させず、導入文を最初の本文としてそのまま表示する（AI が膨らませる方式は不採用。将来トグル追加は可能性として残す）。
- **セッション設定 UI は3案すべてをブランチで実装**して実機で試し、採用案を選ぶ（タブ強調／縦1ページ／左セクションナビ）。
- **カセット PNG の取り込みは「棚に登録のみ」**: 即セッション化はやめ、遊ぶときに「▶ 遊ぶ」で新しいセッションを作る。棚＝素材、と役割を明確化。
- 主人公像（`story.protagonist`・`WorldStartPreset.protagonist`）は削除。
- 分岐ツリーの症状は「枝が1本につながって見える」で確定（診断と一致）。

## 3. プロンプト注入タイミング（FB2-5 への回答の記録）

大原則: **system プロンプトは生成のたびに毎回ゼロから組み立て直す**（`prompts.ts buildSystemPrompt`）。「一度だけ注入」される項目は存在しない。

| セッション設定の項目 | 入り方 |
|---|---|
| タイトル | 入らない（表示専用） |
| 参加キャラ | 毎回【登場人物】（現在シーンの登場キャラのみ。人格・口調・外見・成長・セリフ例） |
| 世界観 | 毎回【世界観】。概要は常に全文、ロアは直近の会話にキーワード一致した項目のみ都度選別 |
| ペルソナ | 毎回【ユーザーが演じる人物】 |
| ジャンル・トーン／あらすじ・前提／主人公像 | 毎回【物語設定】（story モードのみ） |
| 固定メモ | 毎回【常に踏まえる重要事項】 |
| タイムライン | 毎回【時間】（現在の日・時間帯・残り日数。残り15%でクライマックス促し） |
| 選択肢で進行 | 本編には入らない（応答後に選択肢用モデルへ別リクエスト） |
| 演出ディレクター | シーン切替時に抽選→採用タイプの guidance がそのシーン中毎回【今回のシーンの方向性】 |
| モデル・創造性・最大トークン | 入らない（API パラメータ） |
| 文体スタイル／構造化出力 | 毎回（執筆ルール／【セリフの出力形式】ブロック切替） |

設定項目以外に毎回入るもの: これまでのあらすじ（終了シーンの要約）・現在の場面（シーン状況メモ）・状態（関係性/気分/注入対象スタット）。会話履歴は現在シーンの発言のみ全文。

## 4. フェーズ計画

### FB2-A: 即効修正（実装済み・2026-07-11）

- **A1**: `newSession` の `maxTokens` 既定を 4096→32768（スライダー最大に一致）。既存セッションは不変。
- **A2**: `drag-over` の付与先を `.card-grid`/`.library-empty` から `.library` ルートへ移動（Character/World/Persona の3ライブラリ）。CSS は `.library.drag-over`（outline 内側 + accent-soft 背景）に置換。
- **A3**: `SessionCardModal` を開いた時点で `generateDefaultAvatar` を実行し、「自動生成」を**プレビュー付きサムネイル**（「タイトルから自動」キャプション）に変更。挿絵ゼロでもサムネを表示。ObjectURL はアンマウントで revoke。
- **A4**: `renderMainNode` の枝描画を `offChildren.map(c => <div className="bt-alt">{renderSubtree(c.id)}</div>)` に変更（枝ごとに独立した囲み）。`.bt-alt + .bt-alt { margin-top: 8px }` で枝間に間隔。

### FB2-B: 開始体験（導入文・主人公像削除・開始時間帯）

**B1: 導入文（そのまま掲載方式）**
- `types.ts`: `session.story` を `{ genre, premise, opening, openingTitle }` に変更（`protagonist` 削除＝B2）。`WorldStartPreset` も同様に `protagonist` 削除・`opening?`/`openingTitle?` 追加。
- `store.ts`:
  - `newSession` の story 初期値更新。
  - `startPresetPatch`/`hasStartPreset` に opening/openingTitle を追加、protagonist を除去。
  - `startStory`: `story.opening` が非空なら **AI 生成せず** assistant メッセージ（content=opening, sceneId 付与）を積む。シーン title は `openingTitle` 非空ならそれを優先（空なら従来の抽選タイトル）。イベント消化・タイプ抽選は従来通り走らせてよい（guidance は次の生成から効く）。チェックポイント記録（kind:action・label「🎬 導入」等）→ choiceMode≠off なら `genChoices()`。空なら従来通り `beginScene()`。
- `prompts.ts`: `buildSystemPrompt` の `主人公:` 注入行を削除。
- `SessionEditor.tsx`: 主人公像欄を削除し、「導入（最初のシーンの見出し／本文・任意）」欄を追加（story モードのみ）。説明文で「あらすじ・前提=毎回注入される背景／導入=開始時に一度だけ掲載される本文」の違いを明記。
- `WorldEditor.tsx` 開始テンプレート: 主人公像欄→導入欄（見出し＋本文）に差し替え。
- `cards.ts`: `normalizeStartPreset` を更新（protagonist 読み捨て・opening/openingTitle 受理）。
- 互換: optional 追加＋不要フィールド削除のみ → persist キー据え置き。旧データ・旧カードの protagonist は参照されず無害。

**B3: 開始時間帯**
- `types.ts` `Timeline`: `startDay?`/`startSlot?` を追加（既定 1／0）。
- `SessionEditor.tsx` 進行タブ: 「現在の日」の横に「時間帯」セレクト（`slots` から選択＝`currentSlot`）。保存時、`messages.length === 0`（未開始）なら `startDay/startSlot` を current と同値に記録。
- `WorldStartPreset.timeline` に `startDay?`/`startSlot?` 追加 → `startPresetPatch` で current/start 両方へ反映。WorldEditor のテンプレ編集に開始日・開始時間帯入力を追加。
- `cards.ts freshSessionOf`: `currentDay: tl.startDay ?? 1, currentSlot: tl.startSlot ?? 0` に変更（カセットが「1日目の夜開始」等を保てるように）。

### FB2-C: セッション設定 UI（3案をブランチで試作）

main から3ブランチを切り、それぞれ実装して実機比較。採用案を main にマージし残りは削除。
- `fb2c-tabs-emphasis`: 現行4タブのまま、アイコン付き・大型の明確なタブデザインに（変更最小）。
- `fb2c-single-page`: タブ廃止。全項目を大きなセクション見出し付きで縦1ページに。
- `fb2c-section-nav`: WorldEditor と同じ左セクションナビ方式（モーダルを大きく使う）。

### FB2-D: ライブラリ操作性（右クリック＋複数選択削除）

- 対象: セッション一覧（Sidebar）＋キャラ／世界観／ペルソナ／演出の各ライブラリ。
- カード右クリック→ `MenuPopover`（編集／カードとして書き出す／削除。演出は書き出し無し）。
- 複数選択: Ctrl+クリック=個別トグル、Shift+クリック=直近アンカーから範囲（visible 配列順）。選択中は `.selected` 表示、右クリックで「選択した n 件を削除」（セッションは＋一括アーカイブ）。Escape／通常クリックで解除。
- 削除確認は `appConfirm({danger:true})`。通常クリックの「開く」は従来通り。

### FB2-E: カセット棚

- `types.ts`: `Cassette { id, title, description, coverImageId?, session: Session, createdAt }`（session は開始状態。参照素材はライブラリへマージ済みの id 参照）。
- AppState 直下に `cassettes: Cassette[]`（persist 対象・partialize に追加）。
- **GC 規約**: `collectUsedImageIds` に cassettes 分（`sessionImageIds(c.session)` ∪ `coverImageId`）を追加。
- `exportBundle`/`importBundle` に cassettes を追加（画像同梱オプションの対象）。
- 取り込み変更: `importCassette` を「棚に登録のみ」へ（素材マージ・画像 remap は従来通り、セッションは作らない。カバー画像=カード PNG 自体を `putImage`）。Sidebar D&D／System ページの文言更新。
- `playCassette(id)`: `cassette.session` を新 id で複製して sessions へ追加・アクティブ化（何度でも最初から）。
- UI: Library ナビに「🎮 カセット」追加（一覧カード=カバー・タイトル・紹介文・▶遊ぶ・PNG書き出し・削除）。Sidebar の新規作成ボタン列に「🎮 カセットから」→ 棚から選ぶ or PNG 読み込みのモーダル。
- `SessionCardModal` からの書き出しは従来通り（書き出し時に棚へも登録するかは実装時に判断）。

## 5. 検証

各フェーズで `npx tsc --noEmit` → `npm run build`。見た目・UX の実機確認はユーザー担当（完了報告に確認手順を明記する）。FB2-A の確認項目:
1. 同じ地点から3つ以上分岐を作り、「⑂ 別の分岐」を開くと枝が**別々の囲み**で表示される
2. セッションカード化モーダルの「タイトルから自動」にプレビュー画像が出る・クリックで選択枠が付く
3. 新規セッションの最大トークンが 32768 になっている
4. カード PNG をライブラリへドラッグすると点線枠がページ全面に出る
