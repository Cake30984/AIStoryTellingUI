# 実験_対照読み比べ（中核主張の検証・計画 P6）

**確かめたい主張**: 「シーン／レビューの状態機械があると、長編でも素のチャットより読める」。
AI が用意するのは道具（このファイルと `scripts/baseline.mjs`）まで。**読ませる・判定するのは人間**。判定 LLM は使わない（過去に測れなかった。`決定記録.md` §2）。

## 1. 材料（2本）

同じ素材（サンプル「霧坂高校 天文部」）・同じモデル・同じ温度 0.9・同じ「続けて」30回で、**違いは状態機械の有無だけ**にする。

| | A: デリスト側 | B: 対照側（素のチャット） |
|---|---|---|
| 作り方 | アプリでサンプルのセッションを開き、「続ける」を **30回** | `node scripts/baseline.mjs --model <A と同じモデル> --key <キー>`（N 既定 30。他の OpenAI 互換サーバは `--base-url`、`--dry-run` で system を確認） |
| 状態機械 | シーン分割・あらすじ・レビュー A/B/T・ロアのキーワード注入 | **無し**。定義（世界・ロア全件・登場人物・開始時の場面・予定・文体ルール）を1枚の system に貼り、導入文を最初の assistant にして「続けて」を繰り返すだけ |
| 出力 | 「物語を書き出す」→ 範囲: 全体／形式: Markdown／挿絵なし → 保存 | `scripts/out/baseline-<モデル>-<日時>.md`（`.meta.json` に使用量・所要時間・system 全文） |

**A の遊び方の決まり**（人が介入しない＝比較の対象は機構だけ）:
- 入力欄に何も書かない。〈展開を選ぶ〉〈もっと詳しく〉〈先へ飛ばす〉「やり直す」は使わない
- **「続ける」5回ごとに「このシーンを終える」**（＝30回で6シーン）。「シーンが長くなってきました」の案内が先に出たらその時点で終える。レビューは編集せず承認（次シーンの候補は先頭を選ぶ）
- 生成が途中で切れたら「続きを生成」（これは「続ける」に数えない）
- 起案（一行から始める）は使わない。サンプルの素材・導入文のまま

**そろえる作業**（渡す前に）:
- A の Markdown から `## シーン見出し` と末尾の出典行（`*デリスト『…』より*`）を消す。B には最初から無い
- どちらも文頭は同じ導入文で始まる。文字数を数えて `実験メモ` に控える（B は `.meta.json` の `bodyChars`）
- 同じ日に同じモデルで作る。モデルは OpenRouter の同一 id（A の System 画面の既定モデルと B の `--model` を一致させる）

## 2. 読者への渡し方

- 読者は **3人以上（5人推奨）**、作者以外。日本語の小説を読む習慣がある人
- 読者ごとにコインを投げて A/B の順を決め、**「作品1」「作品2」とだけ**ラベルを付ける。どちらがアプリ製かは言わない。ツールの存在も伏せる（「AI に続きを書かせた物語2本」とだけ）
- 2本とも全文を渡す（30ターン ≒ 1〜1.5 万字ずつ。読了 20〜30 分×2）。同じ書式（テキストか PDF）で
- 読み終えてから質問票に答えてもらう。途中でやめた場合は「どこでやめたか」も書いてもらう
- 記録する: 読者 id／作品1＝A か B か／回答／読了か途中か

## 3. 質問票（外部フォームに貼る文面）

前置き: 「AI に続きを書かせた物語を2本読んでもらいました。作品1・作品2について答えてください。良し悪しの正解はありません」

1. **読み進めたいか**（作品1・作品2 それぞれ）— 「途中でやめたくなった／最後まで惰性で読めた／続きが気になった」の3択
2. **人物が一貫しているか**（それぞれ）— 「途中で別人のようになった人物がいた／少し揺れたが同じ人物だと分かった／終始一貫していた」の3択
3. **矛盾に気づいたか**（それぞれ）— 「気づいた（あれば書いてください: 場所・時間・出来事・人物の言動）／気づかなかった」＋自由記述
4. **どちらを続けて読みたいか** — 「作品1／作品2／どちらでもない」の3択（**判定に使う設問**）
5. **自由記述** — 「どちらか一方にだけあった良い点・悪い点を、思いつくだけ」

## 4. 判定

- 設問4で **3人以上が B（対照）を選んだら、中核主張は成立していない**。→ 状態機械を売りにしない。P4 以降の優先順位（起案・公開の文言）を見直し、`計画_レビュー対応.md` §1 の後ろにメモして次の判断へ
- 3人以上が A を選んだら成立。README・公開の説明に「長く読んでも人物と出来事が保たれる」と書いてよい（数字は書かない）
- どちらも3人に届かない（割れた・「どちらでもない」が多い）なら**差が示せていない**。主張は書かず、設問2・3の自由記述を読んで次に測るものを決める
- 結果は日付・モデル・人数・設問4の内訳の1行を `決定記録.md` §7 に追記する。本文2本と質問票の回答は `scripts/out/` に置く（ignore 済み。公開しない）

## 5. やらないこと

判定 LLM による自動評価／アプリ内の実験モード／読者への誘導（どちらがアプリ製かを匂わせる説明）／3人未満での判定。
