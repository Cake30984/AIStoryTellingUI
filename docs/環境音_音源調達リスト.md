## 1. ライセンス方針 — **CC0 のみ**

`公開計画_マネタイズと配布.md` の通り本アプリは有料配布を想定しており、音源は**インストーラに実ファイルとして同梱される**。この2条件が配布元の選択を強く縛る。

- **CC0（パブリックドメイン相当）に限定する。** 帰属表記不要・再配布可・改変可。CC-BY は使えるが、20〜30本ぶんの帰属表記を製品内に維持し続ける運用コストが恒久的に発生するので v1 では避ける。
- CC0 でも**出所は記録する**（`AmbientSoundDef.credit` に「出所 URL / 作者名」を残す）。表示義務は無いが、後からライセンス根拠を辿れないと差し替え判断ができなくなる。

### 使ってよい配布元

| 配布元 | 判定 | 備考 |
|---|---|---|
| **[OpenGameArt](https://opengameart.org/)** | ◎ **実際に使えた** | 高度な検索で「Sound Effect ＋ CC0」に絞れる（`field_art_type_tid[]=13&field_art_licenses_tid[]=4`）。**ログイン不要で直接ダウンロードできる**のでここは Claude が処理できる。ゲーム用途なので最初からループ前提の素材が多い。ただし屋内・都市・生活音（喫茶店・柱時計・電車）はほぼ無い |
| **[Freesound](https://freesound.org/)** | ◎ ただしユーザーのみ | 検索後、右の licenses セクションで **「Creative Commons 0」** を選ぶと CC0 のみに絞れる。環境音の質と量は最良。**ダウンロードにアカウントが必要で Claude は落とせない**（アカウント作成・ログインは行わない）ので、未取得分はここをユーザーが引く |
| **Wikimedia Commons** | × 実質使えなかった | 音声ファイルは大半が CC BY-SA 4.0 か CC BY 4.0。ambience 系キーワードで CC0 を数えると各0〜4件で、使えるものが無かった（環境音の充実した "Gravity Sound" 一式も Commons 上は **CC BY 4.0**）。CC0 方針を保つ限りここは当てにならない |
| **Sonniss GDC Game Audio Bundle** | ○ 条件付き | 無料・商用ゲーム利用可のロイヤリティフリー。生素材が長く大きいので切り出し加工が前提。**同梱可否をライセンス条文で必ず確認**（CC0 ではない） |

### 使わない配布元（理由つき）

| 配布元 | 除外理由 |
|---|---|
| **Pixabay** | 現行の Pixabay Content License は「素材をそのままの形で再配布・販売する」ことを認めていない。アプリに `.ogg` として同梱するのはこれに触れうる。商用製品では避ける |
| **Zapsplat / SoundBible 等の「無料・帰属表記必須」系** | 帰属表記の恒久運用コスト＋独自ライセンスの再配布条項が個別確認になる |
| **BBC Sound Effects（RemArc）** | 個人・教育・研究用途に限定。商用不可 |

> ライセンス条文は改定される。**実際に落とす直前に各素材のページで CC0 表記を確認**すること（Freesound は素材ごとにライセンスが違う＝サイト単位で安全ではない）。

### 素材選びの基準（重要）

1. **定常テクスチャであること。** 目立つ単発音（車のクラクション・犬・話し声の意味が取れる会話）が入っているものは避ける。ループで同じ位置に同じイベントが来ると強く気づかれて没入が切れる。
2. **旋律・拍が無いこと。** 音楽的要素が入っていると読書の内なる声と競合する（要望書 §2-4）。
3. **30秒以上あること。** 短いと加工後のループ周期が短くなり、反復に気づかれる。理想は 60〜120 秒の素材から 45 秒を切り出す。
4. **モノラルで成立すること。** 同梱サイズを抑えるためモノラルへ落とす。強い左右の動きがある素材はモノラル化で潰れるので不向き。
5. **蝉・雑踏など「意味を持つ音」は世界観を限定する。** それでも入れる価値があると判断した（日本の夏・街の記号は強い）が、汎用セットの中では少数派に留める。

## 3. ダウンロードの手順（ユーザー・**未取得分だけ**）

§0 の「未取得」リストが対象。★の3本（`waves-shore`・`cafe`・`clock-tick`）が揃うと ★8本が完成する。

1. [Freesound](https://freesound.org/) にログイン（ダウンロードにアカウントが必要）。
2. 上の表の英語検索語で検索 → 右の **licenses → 「Creative Commons 0」** を選ぶ。
3. 試聴して §2 の基準を満たすものを選ぶ。**WAV / FLAC など非圧縮の元データを落とす**（MP3 から再圧縮すると劣化が乗る）。
4. **1つのフォルダにまとめて置くだけでよい。** ファイル名は元のままでよい（対応付けは次のステップで私が確認する）。置き場所は `docs/` や `src/` の外——例えば `C:\Users\<user>\tool\AIStoryTellingUI\_ambient_src\` のような作業フォルダ（`.gitignore` 対象にする）。
5. 各素材の **ページ URL と作者名**を控える（テキストファイルに貼るだけでよい）。`credit` フィールドに入れる。

★の8本だけ先に集めれば AM1 の体感検証に入れる。

## 4. 加工の手順（Claude・`ffmpeg` 8.1.1）

置いてもらった生素材に対して私が実行する。**ユーザーがやる必要は無い**（記録として残す）。

```bash
# ① 良い区間を 48 秒切り出し・モノラル・48kHz
ffmpeg -i src.wav -ss 12 -t 48 -ac 1 -ar 48000 step1.wav

# ② 音量を -23 LUFS に統一（素材ごとの音量差があると「到達半径」の体感が壊れる）
ffmpeg -i step1.wav -af loudnorm=I=-23:TP=-2:LRA=7 step2.wav

# ③ 末尾3秒を先頭へクロスフェードして継ぎ目の無いループにする（出力は45秒）
ffmpeg -i step2.wav -filter_complex \
  "[0:a]atrim=0:45,asetpts=N/SR/TB[a];[0:a]atrim=45:48,asetpts=N/SR/TB[b];[b][a]acrossfade=d=3[out]" \
  -map "[out]" step3.wav

# ④ OGG Vorbis へ（1本 300〜600KB 目安）
ffmpeg -i step3.wav -c:a libvorbis -q:a 3 -ac 1 -ar 48000 src/assets/ambient/<id>.ogg
```

実際の実行では上記を1本のスクリプトにまとめ、素材長に応じて窓とクロスフェード長を自動で決めている（素材が20秒未満なら `xf = 長さ×15%`、目標長 = `min(45, 使える長さ − xf)`）。②は**2パス**（`print_format=json` で測ってから `measured_*` を渡す `linear=true`）で、単パスの動的正規化が疎な素材でポンピングするのを避けている。

- ③ のクロスフェードで継ぎ目が残る素材（周期的なパターンを持つもの）は、切り出し位置を変えて作り直す。最終判断は**ユーザーが実際にループを聴いての体感**。
- 加工後に `-23 LUFS` を `ffmpeg -i <id>.ogg -af loudnorm=print_format=summary -f null -` で検算する。
- **⚠ 疎な素材（滴り・単発が主体）は積分ラウドネスで揃わない。** `cave-drips` は2パス linear では -28.7 LUFS にしかならず（静寂が大半＋ピークが高いため linear モードがゲインを出せない）、`volume=+5.7dB,alimiter` の素直なゲインで -24.4 に寄せた。同種の素材が増えたら、カタログに音量補正フィールドを足す（＝設計 §6 の「補正を持たせない」を見直す）か、ゲインをファイルに焼き込むかの判断が必要になる。**今は焼き込みで通している。**
- 全部揃ったら合計サイズを確認（目標 5〜10MB）。取得済み16本で 4.4MB。
